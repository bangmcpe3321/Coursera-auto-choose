# Gemini Solver (Userscript)

> "Why need to choose individual question when u can make it auto choose?"

This script is a browser tool designed to assist with online quizzes and assignments on Coursera.

## Why use this script?

*   **🧠 Automated Solving**: Instantly matches answers from your clipboard (e.g., from an AI response or notes) to the correct options on the quiz page.
*   **⚡ Efficiency**: Dramatically reduces the time spent on repetitive quizzes and assignments by automating the selection process.
*   **🎓 Auto-Peer Grading**: Features an "Auto Peer Grade" button that automatically selects the maximum points for peer review rubrics, streamlining the grading process.
*   **🛡️ Robust Answer Matching**: Uses intelligent fuzzy matching algorithms to correctly identify answers even with slight variations in formatting or wording.

## Installation

1.  Install the **Tampermonkey** extension for your browser.
2.  Create a new script in Tampermonkey.
3.  Copy and paste the content of `Gemini.js` into the editor.
4.  Save the script.
5.  Navigate to a supported quiz page (e.g., Coursera) to see the "Manual Solver" panel.

## Usage

1.  Open a quiz on a supported platform.
2.  Get the solutions (e.g., from an AI assistant or notes).
3.  Copy the solution text to your clipboard.
4.  Paste the text into the "Manual Solver" panel on the quiz page.
5.  Click "Match & Select".
6.  The script will automatically select the matching options.
